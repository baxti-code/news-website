# Django News Website

A news website built with Django featuring categories, 
admin panel, authentication, and contact form with email notifications.

## Tech Stack
- Python / Django
- SQLite
- HTML/CSS/JavaScript (Bootstrap)

## Features
- News categories and filtering
- Admin panel with custom configurations
- User authentication (login, register, password reset)
- Contact form with Gmail SMTP
- Slug-based URLs
- Image upload support

## Frontend Template
The frontend template was downloaded from 
the internet for learning purposes.
Backend integration and Django implementation done by me.

## Installation
```bash
git clone https://github.com/baxti-code/news-website.git
cd news-website
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
